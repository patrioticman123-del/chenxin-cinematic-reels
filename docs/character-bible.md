# 醫師角色規範

- 固定角色：宸新復健科醫師，以使用者提供並授權的醫師照片為準
- 外型：年輕東亞男性，短黑髮、自然微笑、面部五官盡量保持本人特徵，略為動畫化而不失真
- 穿著：白袍、淺藍襯衫、深藍領帶、深色長褲
- 性格：親切、穩重、專業，用白話說清楚醫療觀念
- 動作：真實步態、轉身、抬手指示解剖部位、與觀眾角色對談
- 角色一致性：不同鏡頭不可突然變臉、變裝、身高變化或肢體異常
- 旁白：台灣中文男聲，不可誤稱是醫師本人錄音
- 不使用外星人代替醫師
- 醫師照片檔建議位置：`assets/character/doctor-photo.jpg`
- 每支影片的生成任務都應再次提供同一張角色參考照和相同特徵描述
