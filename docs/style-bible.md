# 視覺與鏡頭風格

## 目標
9:16 直式寫實電影感 3D（稍微動畫化的醫師）與巨大人體微縮冒險。敘事優先，不做成純圖卡投影片。

## 場景
- 真實日常環境引入問題，再切入巨大關節、肌腱、筋膜、神經等解剖世界
- 巨型器官與微縮人物比例清楚、光影有層次、材質寫實
- 人體模型需符合基本解剖關係；奇幻場景效果不可造成醫學誤解

## 鏡頭
- 追蹤兩人向前行走（tracking shot）
- 醫師手勢引導（medium shot）
- 放大組織與關節表面（macro close-up）
- 快速推鏡與合理轉場（dolly-in / cutaway）
- 單鏡頭通常 2–4 秒，重要概念可保留更久
- 須有真實連續影格；單張照片的 Ken Burns 只算替代預覽

## 字幕
- 繁體中文，避免一幕過多文字；字體清晰、對比足夠
- 字幕在後製加上，不要要求影片生成模型將中文字烘焙在畫面裡
- 保留手機上下安全區，不要遮住解剖重點或醫師臉部

## 畫質
- 目標 1080x1920，30fps，H.264
- 720p 或 540p 放大到 1080p 只是輸出尺寸變大，不等於原生高清
- 醫師臉、手、衣服、組織接縫要檢查有無變形
